# AI Search — local implementation, 2026-11-07

Status: implemented locally; not deployed or pushed. No API key configured and no paid/live OpenAI calls made. Live model quality, latency, token usage and model/API compatibility remain unverified.

## Behaviour

AI Search is in the mobile More menu and desktop sidebar. Users describe a movie or series; submitting is the only action that invokes the model. Existing results stay visible during a new search. Poster cards link to normal media actions and include short reasons for subjective suggestions. Edit the description and submit again to refine; there are no separate editable filter controls in this first version.

Server-only OPENAI_API_KEY; model gpt-6.1-terra, medium reasoning, Responses API, store=false. The client cannot supply credentials. No history, reviews, or credentials are sent to the model; only the submitted description and interpretation instructions. If users include personal information in their description, that text is sent. Never log Axios errors (they include Authorization). No production secret storage has been configured.

The model returns a validated search plan, never trusted catalogue IDs. Subjective suggestions resolve by exact normalized title/original title plus year; ambiguous or missing matches are omitted. Objective queries use TMDB discovery. Availability, watched status, genres, year and runtime are enforced locally. Series runtime means episode runtime; unknown runtime fails a runtime constraint. Unwatched requests fail explicitly when history is unavailable. Existing discovery attribution includes co-viewers. Blocklisted media is excluded. TV availability currently requires full availability, not partially available seasons.

## Bounds and limitations

- 20 model attempts per user/hour, two simultaneous model calls per process.
- Interpretation cache: per user/query, ten minutes, at most 100 entries. Results and personal state are rechecked, not cached here. Limits reset on restart.
- Up to 16 suggested titles or three discovery pages (60 candidates); up to 20 displayed matches. Metadata batches of three; existing TMDB caches apply.
- This is explicitly a shortlist, not exhaustive library search. Sparse available/unwatched matches may return fewer or zero results. No automatic refill/model loop.
- Runtime lookup only after inexpensive availability/watched/blocklist filtering.
- Model output ceiling 4,000 tokens; request timeout 45 seconds; invalid/incomplete output safely fails. Actual API support/quality awaits a key.
- Unsupported constraints are disclosed in the model note; suggestions and sensitive-content claims require user judgment. No recommendation scheduling or Letterboxd writes.
- No loading requests from opening the page or typing; no scheduled work, migrations, live state edits or toggle changes.
