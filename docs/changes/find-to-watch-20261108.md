# Available-library browsing and automatic people filters — local only

2026-11-08. Not deployed; no production data/toggle changes or paid AI calls.

For You's clock/people shortcuts are replaced with one Heroicons lightbulb linking to `/find-to-watch`. Previous full-section routes remain valid. The new current-user page offers Movies/Series, shared people picker, existing editable filter chips and sort popover. Availability is enforced server-side and hidden as an editable filter. The pool includes available titles and partially available series, excluding blocked titles through existing discovery availability. Unwatched uses Watch Together's shared exclusion logic. Best match starts with cached For You ranking, then remaining available titles.

Infinite scroll uses the existing `useInView` pattern, fetching 20-title server batches. No Previous/Next/page-number controls. Loading more preserves existing posters; status/spinner appears below. Appends deduplicate IDs. Changing filters/type/people/sort resets the results and scroll cursor; errors stop automatic continuation and offer Retry.

Opening an unfiltered view reads only one page of base metadata and starts no score scan. Runtime/year/genre filters or ordering require a complete matching pool before global sorting/pagination. Base movie/series metadata uses lightweight unappended TMDB calls and existing 12-hour cache, at most two simultaneous library metadata reads across jobs. Ratings use the existing four-worker persisted score queue, in batches of 40. Full-library cold checks can take time; the UI displays actual stages and completed/total counts rather than presenting a partial ordering as complete. Missing metadata is counted; score filters exclude unknown scores, while sort-only places them last.

Private per-user background jobs expose lightweight progress while pending (1.5s checks), rather than repeatedly fetching the whole result set. At most 64 retained jobs, 15-minute lifetime; a new filter request cancels that user's older unfinished job after its current bounded work. Completed matching jobs reuse results for later pages. Expired/changed visibility fails closed. Jobs are memory-only and restart requires retry; no scheduled jobs or full-library warmup added. Progress endpoint checks job owner and current discovery visibility. Authenticated API schema validated with no OpenAI key configured.

AI Search's people picker now automatically reapplies watched filters after a 300ms coalescing delay. Existing search filters and sort are sent with the cached interpretation; no additional AI call. Requests are aborted on replacement/unmount and late responses/progress are ignored. Checkbox changes remain available while processing. Removing a person named in the original prompt no longer re-adds them during a filter edit; names are still stripped to preserve the same interpretation cache key. Original submissions retain name resolution. Explicitly selecting Include watched remains allowed after group selection.
