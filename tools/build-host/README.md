# Default catalogue builder

From the Mac run `node tools/build-host/deploy.cjs <scoped-manifest.json>` in seerr-fork. The existing seerr-social/deploy-catalogue.cjs entrypoint delegates here. The manifest contains an explicit files array relative to the catalogue source. Use one invocation and await its exit. The existing live Git snapshot and rollback procedure apply.

Mini owns the release lock, snapshots its source, overlays the reviewed changes and sends the allowlisted build input over native Windows SSH to PRPL-PC (MSI, port 2222). C:/ProgramData/Seerr/build-host contains mini-build.cjs, restore-links.cjs and smoke-trial.cjs. PRPL-PC keeps its portable Windows x64 Node 22.23.2, pnpm 10.24.0, frozen dependency store, working directory and tools under D:/CatalogueBuilder. Install pc-build.cjs and export-links.cjs in its tools directory. Mini's release account must already trust and authenticate to the PC. No live DB, settings, .env, keys, or service credentials are build inputs. An unreachable builder fails the build; the current catalogue remains online.

Every build refreshes the working source, runs a frozen install, compiles both halves and exports .next and dist. Cache, traces and .next/node_modules are excluded. A per-release receipt binds the input digest, artifact digest, link manifest digest, tool versions and build ID. Mini checks the hashes, rebuilds every generated alias as a junction to the exact installed pnpm path after validating package name and version, and exercises the staged login page, JavaScript chunks, compiled list/review modules and native in-memory SQLite. Those checks run on loopback before the Caddy lease. Dependency changes that require installing new runtime packages on Mini must be provisioned deliberately; do not bypass a preflight failure.

After preflight the release verifies Caddy's public maintenance page, stops Seerr, backs up state, switches the already-tested .next and dist, starts the service, checks the direct APIs, clears the lease and verifies public health. Rollback uses the same expiring lease. Receipts and rollback files are kept under Mini's release directory; transfer archives are removed after preflight. D:/CatalogueBuilder/work is reused for subsequent builds. The trial helpers remain as the historical acceptance harness.
